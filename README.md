# Shop Sales Insights

A local application for recording daily bills and analysing sales and customer
behaviour for a single grocery shop in Sri Lanka.

Built with Python, Streamlit, SQLite, Pandas and Plotly as a learning project.

## Status

In development. See `docs/PROGRESS.md`.

## Privacy

This repository contains source code only. Business data (the database, backups
and exports) is stored locally and is excluded from version control.
